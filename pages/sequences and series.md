- introduction
	- `sequence`: collection of objects listed in a sequence, means that the collection is ordered in a such a way that it has an identified first member, second member, third member and so on.
	- `sequences` following specific patterns are called `progressions`
- sequences
	- various numbers occurring in a sequence are called its `terms` denoted by $a_1, a_2, a_3. ..., a_n, ..., etc.,$, subscripts denote the position of the term.
	- $n^{th}$  term is the number at the $n^{th}$ position of the sequence and is denoted by $a_n$, is also called the `general term` of the sequence.
	- a sequence containing finite number of terms is called a `finite sequence`.
	- a sequence is called `infinite`, if it is not a finite sequence.
	- it is possible to express the rule, which yields various terms of a sequence in terms of algebraic formula.
		- example: the sequence of odd natural numbers 1, 3, 5, ...., the $n{th}$ term is given by the formula, $a_n = 2n - 1$, where n is a natural number.
		- Fibonacci sequence: 1, 1, 2, 3, 5, 8, ....
			- the sequence is generated by the recurrence relation given by
			  $a_1 = a_2 = 1$
			  $a_3 = a_2 + a_1$
			  $a_n = a_{n-1} + a_{n-2}$, n > 2
		- the sequence of primes 2, 3, 5, 7, 000, we find that there is no formula for the $n{th}$ prime. such sequence can only be described by verbal description.
		- in every sequence, we should not expect that its terms will necessarily be given by a specific formula. however, we expect a theoretical scheme or a rule for generating the terms $a_1, a_2, a_3. ..., a_n, ...$ in succession.
		- a sequence can be regarded as a function whose domain is the set of natural numbers or some subset of it of the type {1, 2, 3, ..., k}. functional notation a(n) for $a_n$
- series
	- $a_1, a_2, a_3. ..., a_n$ be a given sequence, then, the expression $a_1 + a_2 + a_3 + ... + a_n + ...$ is called the `series associated with the given sequence`. the series is finite or infinite according as the given sequence is finite or infinite. series are often represented in compact form, called `sigma notation`, using the Greek letter \sum (sigma) as means of indicating the summation involved. thus, the series $a_1 + a_2 + a_3 + ... + a_n$ is abbreviated as $\sum_{k=1}^{n} a_k$
	- when series is used, it refers to the indicated sum no the sum itself.
	- phrase `sum of a series` mean the number that results from adding the terms.
- arithmetic progression (A.P.)
	- a sequence $a_1, a_2, a_3. ..., a_n, ...$ is called `arithmetic sequence` or `airthmetic progression` if $a_{n+1} = a_n +d$, d \in N, wher$a_1$ is called the first term and the constant term `d` is called the ` common difference` of the A.P.
	- an A.P. with first term `a` and common difference `d`, i.e., a, a + d, a + 2d, ...
	  $n^{th}$ term (general term) of the A.P. is $a_n = a + (n - 1) d$
	  simple properties of an A.P.:
	  1) if a constant is added to each term of an A.P., the resulting sequence is also an A.P.
	  2) if a constant is subtracted from each term of an A.P., the resulting sequence is also an A.P.
	  3) if each term of an A.P. is multiplied by a constant, then the resulting sequence is also an A.P.
	  4) if each term of an A.P. is divided by a non-zero constant then the resulting sequence is also an A.P.
	  a = the first term
	  l = the last term
	  d = common difference
	  n = number of terms
	  $S_n$ = the sum of n terms of A.P.
	- `a, a + d, a + 2d, ..., + a + (n - 1) d` be an A.P. 
	  then `l = a + (n - 1) d`
	- $S_n = \frac{n}{2}[2a + (n-1)d]$
	  we can also write $S_n = \frac{n}{2}[a+l]$
	- arithmetic mean
		- given 2 numbers `a`, `b`. we can insert a number `A` between them so that a, A, b is an A.P. such a number `A` is called the `arithmetic mean` (A.M.) of numbers `a` and `b`.
		  A - a = b - A, i.e., A = $\frac{a + b}{2}$
		- we may also interpret the A.M. between 2 numbers a and b as their average $\frac{a + b}{2}$
		- given any 2 numbers a and b, we can insert as many numbers as we like between them such that the resulting sequence is an A.P.
		- Let $A_1, A_2, A_3, ..., A_n$ be n numbers between a and b such that a, $A_1, A_2, A_3, ..., A_n$, b is an A.P.
		  here, b is the ${n + 2}^{th}$ term, i.e., b = a + [(n + 2) - 1] d =  a + (n + 1) d
		  $d = \frac{b - a}{n + 1}$
		  thus n numbers between a and b are as follows:
		  $A_1 = a + d = a + \frac{b - a}{n + 1}$
		  $A_2 = a + 2d = a + \frac{2(b - a)}{n + 1}$
		  $A_3 = a + 3d = a + \frac{3(b - a)}{n + 1}$
		  ...
		  ...
		  $A_n = a + nd = a + \frac{n(b - a)}{n + 1}$
- geometric progression (G.P.)
	- a sequence $a_1, a_2, a_3. ..., a_n, ...$ is called `geometric progression` G.P. or `geometric sequence`, if each term is non-zero and $\frac{a_{k+1}}{a_k}$ = r (constant), for k $\geq$ 1
	  by letting $a_1$ = a, we obtain a G.P., $a, ar, ar^2, a^3, ...$, where `a` is called the `first term` and `r` is called the `common ratio` of the G.P.
	  a = the first term
	  r = the common ratio
	  l = the last term
	  n = number of terms
	  $S_n$ = the sum of first n terms
	- general term of a G.P.
		- a G.P. with first non-zero term `a` and common ratio `r`
	- sum of n terms of a G.P.
	- geometric mean (G.M.)
